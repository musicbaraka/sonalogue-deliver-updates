# Rules for this repo

This repo is **public**. It holds only the installers and release notes for Sonalogue Deliver.

- Allowed here: this file, the README, and GitHub Releases containing the `.exe` installer, its `.blockmap`, `latest.yml` and release notes text.
- **Never** add source code, passwords, tokens, API keys, `.env` files or any other secret, in files, releases or notes.
- The source code lives in the private repo `musicbaraka/sonalogue-deliver`. Releases arrive here only from its build, after its safety check passes.
- Never use Paul's legal name anywhere. He is Paul Baraka.
